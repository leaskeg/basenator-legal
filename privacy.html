Privacy Policy

Basenator — last updated September 2026

1. What we collect

When Basenator is used in a server, it stores:

  • The Discord server (guild), channel, and message IDs of posts it creates
  • The Discord user ID and username of whoever posted a base/army and whoever clicked "Install" or "Copy Link" on it, along with when they did
  • The content you submit through the bot: the base/army link, your description text, and any picture attached

We don't collect anything else — no message content outside of what's explicitly submitted to the bot, no browsing activity, no personal information beyond what Discord itself provides (user ID and username).

2. How it's used

Solely to run the bot's own features: displaying posts, tracking who's downloaded a base or army, and letting admins edit a post afterward. Nothing is used for advertising, profiling, or any purpose outside the bot's stated functionality.

3. Where it's stored

Data is stored in a database that only the bot can access. Every server's data is kept fully separate from every other server's — there is no shared storage between servers, and no way for one server's admins or members to see another server's posts or download history.

4. How long it's kept

Data for a server is kept for as long as the bot remains in that server. If the bot is removed (kicked) from a server, that server's data is automatically deleted.

5. Third parties

Data is never sold or shared with third parties. The bot operates through Discord's own API, which is governed by Discord's Terms of Service and Privacy Policy — using Basenator means you're also subject to those, same as using any Discord bot.

6. Your options

If you'd like data about a specific post removed, ask a server admin, or contact the developer directly. Removing the bot from your server deletes all of that server's data automatically.

7. Changes to this policy

This policy may be updated as the bot changes. Continued use after an update means you accept the current version.
